# Runway — Shopify theme

Online Store 2.0 theme by IMRAN SAHAB Digital Agency.

Setup: upload the zip (Online Store → Themes → Add theme → Upload zip file), create menus with handles `main-menu` and `shop`,
then open the theme editor → Home → Runway and add a model image and up to three products to each look.

Try-it-on page: Online Store → Pages → add a page, choose template "page.try-on", then add garments (product + optional transparent image) in the theme editor.
